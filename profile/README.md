## What is Manta Client?

Manta Client is a free Minecraft PvP client: a desktop launcher plus a Fabric client mod, built for players who want high FPS, clean PvP mods and an easy way to play with friends. It runs on Minecraft: Java Edition 1.21.11.

<p align="center">
  <img src="https://mantaclient.github.io/launcher.png" alt="Manta Client launcher" width="720">
</p>

## Features

- **Parties** – group up with up to 8 friends. When the leader joins a server, everyone follows automatically.
- **Built-in mods** – performance and quality-of-life mods, a movable HUD, custom crosshair, zoom, no fog, fullbright and more, all in one menu (Right Shift).
- **PvP practice** – bots and drills for aim, strafing and combos, then duel a friend 1v1.
- **Friends list** – see who's online and what server they're on, or appear offline.
- **Mods from Modrinth** – browse and add mods in one click, with every file checked before it runs.
- **Capes and emotes** – original Manta capes you earn by playing, plus a skin manager.
- **Instant clips** – save the last moments of a fight with one key.
- **FPS and lag reports** – plain-English answers to "why is my game lagging?".
- **Discord status** – shows you're playing Minecraft with Manta Client.

## Is it safe?

- You sign in on **Microsoft's own page**. Manta never sees or stores your password.
- Every mod you add is **scanned for known malware** before launch.
- Manta's built-in mods are quality-of-life and visual only, designed to follow server rules. Servers running the Manta plugin can switch individual features off.
